Médiathèque

Ma note
Réglages

Sans réglage, tes médias restent sur cet appareil. Renseigne ton script Google pour synchroniser (Notion ou Google Sheet).

Aide à la configuration

Tout est facultatif : sans réglage, l’app fonctionne seule et garde tes médias sur cet appareil. Pour les sauvegarder et les retrouver sur plusieurs appareils, branche-la à Notion ou à un Google Sheet via un petit script Google (gratuit, à ton nom).

Vue d’ensemble
  1. Tu crées un script Google (étape 1) : c’est la passerelle entre l’app et tes données.
  2. Tu choisis ta source : Notion (2a) ou Google Sheet (2b).
  3. Tu remplis les champs de la page Réglages (3), puis « Enregistrer ».
1 · Créer le script Google (obligatoire)
  1. Va sur script.google.com → « Nouveau projet ».
  2. Supprime le code par défaut et colle le contenu du fichier Code.gs fourni avec l’app.
  3. À gauche, ⚙️ « Paramètres du projet » → « Propriétés du script » → « Ajouter une propriété » : nom APP_KEY, valeur = un mot de passe long de ton choix (ta « clé d’accès »). Pour Notion, ajoute aussi NOTION_TOKEN et DATABASE_ID (étape 2a).
  4. Retourne dans l’éditeur, choisis la fonction autoriser dans la liste, clique ▶ « Exécuter », puis « Examiner les autorisations » → ton compte → « Paramètres avancés » → « Accéder à … (non sécurisé) » → « Autoriser ». C’est normal : le script est le tien.
  5. « Déployer » → « Nouveau déploiement » → roue ⚙️ → « Application Web ». « Exécuter en tant que » : Moi ; « Qui a accès » : Tout le monde (la clé d’accès protège l’URL). « Déployer ».
  6. Copie l’URL de l’application Web (elle finit par /exec) : c’est le champ « URL de l’application web ».
  7. Si tu modifies le code plus tard : « Déployer » → « Gérer les déploiements » → ✏️ → Version « Nouvelle version » → « Déployer ». Sans ça, l’ancien code continue de tourner.
2a · Source Notion
  1. Va sur notion.so/profile/integrations → « Nouvelle intégration » (type interne) → copie le « Secret d’intégration » : c’est NOTION_TOKEN.
  2. Ouvre ta base de données → menu ••• en haut à droite → « Connexions » → ajoute ton intégration. Sans ça, Notion répond « introuvable ».
  3. Ouvre la base en pleine page : l’adresse ressemble à notion.so/…/32caractères?v=…. Ces 32 caractères (avant « ?v= ») sont DATABASE_ID.
  4. Ajoute NOTION_TOKEN et DATABASE_ID dans les propriétés du script (étape 1.3).
  5. Propriétés attendues (majuscules et espaces ignorés) : Nom (titre), Type, Statut (options « Pas commencé », « En cours », « Terminé »), Note sur 5, Auteur, Terminé le, Lien, Cover, Genre, Notes, Résumé. Facultatif : « Ajouté le » ; sinon la date de création de la page sert au tri.
2b · Source Google Sheet
  1. Crée un Google Sheet vierge (sheets.new) avec le compte qui a déployé le script, ou partage un Sheet existant avec ce compte en « Éditeur ».
  2. Copie son adresse complète dans la barre du navigateur : c’est le champ « Lien du Google Sheet ».
  3. Au premier envoi, le script crée l’onglet Médias avec les colonnes Nom, Type, Statut, Note sur 5, Auteur, Terminé le, Lien, Cover, Genre, Notes, Résumé, Ajouté le, ID.
  4. Tu peux aussi remplir le tableau à la main : les lignes sans ID en reçoivent un à la prochaine synchronisation. Statut = Pas commencé / En cours / Terminé ; note = nombre de 0 à 5 ; genres séparés par des virgules ; dates au format AAAA-MM-JJ.
  5. Ne renomme pas les en-têtes, ne touche pas à la colonne ID et n’y mets pas de formules.
  6. Aucune propriété Notion n’est nécessaire : seule APP_KEY compte.
3 · Remplir les champs des réglages
  • Source des données : Notion ou Google Sheet.
  • URL de l’application web : l’adresse en /exec de l’étape 1.6.
  • Clé d’accès (APP_KEY) : exactement le mot de passe saisi dans les propriétés du script.
  • Lien du Google Sheet (source Sheet uniquement) : étape 2b.
  • Clé Google Books et clé TMDB : facultatives, étape 4.

Puis « Enregistrer » : la synchronisation démarre. Si tu changes de source plus tard, l’app te demande quoi faire des médias déjà présents.

4 · Clés facultatives (recherche de fiches)
  1. Google Books (livres) : sur console.cloud.google.com, crée un projet → « API et services » → « Bibliothèque » → « Books API » → Activer → « Identifiants » → « Créer des identifiants » → « Clé API ». Restreins-la : API = Books API uniquement ; applications = sites web, avec l’adresse de ton app suivie de /*. Sans clé, le quota partagé est souvent épuisé.
  2. TMDB (films et séries) : crée un compte gratuit sur themoviedb.org → Paramètres → API → demande une clé (usage personnel) → copie la « Clé d’API » (v3, pas le jeton de lecture).
5 · Installer l’app et changer d’appareil
  • Android (Chrome) : menu ⋮ → « Installer l’application ». iPhone (Safari) : Partager → « Sur l’écran d’accueil ». L’app doit être servie en HTTPS.
  • Nouvel appareil : « Exporter les réglages » sur l’ancien, puis « Importer des réglages » sur le nouveau. Le fichier contient tes clés : garde-le privé.
  • Sauvegarde : « Exporter les données » crée un fichier JSON de tous tes médias.
6 · Problèmes fréquents
  • « Clé invalide » : l’APP_KEY de l’app diffère de celle du script.
  • « Réponse invalide… » : l’URL ne finit pas par /exec, l’accès n’est pas « Tout le monde », ou le script n’a jamais été autorisé (1.4).
  • Notion « introuvable » : intégration non ajoutée à la base (2a.2) ou mauvais DATABASE_ID.
  • Sheet inaccessible : le compte qui a déployé le script n’a pas accès au document.
  • Code modifié sans effet : crée une nouvelle version du déploiement (1.7).
  • Pastille ● sur une couverture : modifications pas encore envoyées ; elles partent au retour du réseau.
  • L’app ne se met pas à jour : ferme-la et rouvre-la deux fois (cache hors ligne).
