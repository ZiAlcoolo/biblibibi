Administrateur

Aide

Biblibibi garde tes médias sur cet appareil. Avec un Google Sheet, tu les retrouves aussi sur tes autres appareils et tu en as une sauvegarde à toi.

Démarrer avec Google Sheet (3 étapes)
  1. Va sur sheets.new pour créer un Google Sheet vide (donne-lui le nom que tu veux).
  2. Clique sur « Partager » et ajoute l’administrateur de l’app en Éditeur. Alternative : « Accès général » → « Tous les utilisateurs disposant du lien » avec le rôle Éditeur.
  3. Copie l’adresse du Sheet dans la barre du navigateur, ouvre ⚙️ Réglages, colle-la dans « Lien de ton Google Sheet » et enregistre.

L’app crée toute seule l’onglet « Médias » et ses colonnes. Ne partage ce Sheet qu’avec des personnes de confiance : quiconque a le lien en édition peut modifier ta liste.

Remplir ou corriger ton Sheet à la main
  • Une ligne = un média. Colonnes : Nom, Type, Statut, Note sur 5, Auteur, Terminé le, Lien, Cover, Genre, Notes, Résumé, Ajouté le, ID.
  • Statut : « Pas commencé », « En cours » ou « Terminé ». Note : un nombre de 0 à 5. Genres séparés par des virgules. Dates au format AAAA-MM-JJ.
  • Les lignes sans ID en reçoivent un à la prochaine synchronisation. Ne touche pas à la colonne ID, ne renomme pas les en-têtes et n’y mets pas de formules.
Changer d’appareil, installer, sauvegarder
  • Sur le nouvel appareil, ouvre l’app et colle le même lien de Sheet dans les réglages : tes médias reviennent.
  • Installer l’app : Chrome Android → ⋮ → « Installer l’application » ; iPhone (Safari) → Partager → « Sur l’écran d’accueil ».
  • « Exporter les données » crée une copie JSON de ta liste sur l’appareil.
Problèmes fréquents
  • « Impossible d’ouvrir le Sheet » : le lien est incorrect ou le Sheet n’est pas partagé en Éditeur avec l’administrateur.
  • « Clé invalide » ou « Réponse invalide » : l’app n’est pas (ou plus) bien configurée côté administrateur ; préviens-le.
  • Pastille ● sur une couverture : modifications en attente d’envoi, elles partent au retour du réseau.
  • L’app ne se met pas à jour : ferme-la et rouvre-la deux fois.
Admin · Mettre en place le script partagé
  1. script.google.com → « Nouveau projet », colle le contenu de Code.gs.
  2. ⚙️ « Paramètres du projet » → « Propriétés du script » : APP_KEY (clé partagée par les amis, à copier dans CONFIG), ADMIN_KEY (ta clé personnelle, réservée à Notion) et, pour Notion, NOTION_TOKEN et DATABASE_ID.
  3. Exécute la fonction autoriser et accepte les autorisations (« Paramètres avancés » → « Accéder à … »).
  4. « Déployer » → « Nouveau déploiement » → « Application Web » : Exécuter en tant que Moi, Accès Tout le monde. Copie l’URL en /exec.
  5. Dans index.html, remplis l’objet CONFIG : SCRIPT_URL, APP_KEY (la même que dans le script), SHARE_EMAIL (ton adresse Google) et, si tu veux, GBOOKS_KEY / TMDB_KEY. Puis republie l’app.
  6. Après chaque modification de Code.gs : « Déployer » → « Gérer les déploiements » → ✏️ → « Nouvelle version ».
Admin · Source Notion (ta base perso)
  1. notion.so/profile/integrations → nouvelle intégration interne → copie le secret (NOTION_TOKEN).
  2. Dans ta base : ••• → « Connexions » → ajoute l’intégration. DATABASE_ID = les 32 caractères de l’adresse avant « ?v= ».
  3. Dans Réglages (mode admin) : Source « Notion » et ta ADMIN_KEY dans « Clé admin ». L’URL du script est déjà préremplie.
  4. Propriétés attendues : Nom, Type, Statut (Pas commencé / En cours / Terminé), Note sur 5 (sélection ou texte), Auteur, Terminé le, Lien, Cover, Genre, Notes, Résumé. Facultatif : « Ajouté le ».
Admin · Clés Google Books et TMDB (partagées)
  1. Google Books : console.cloud.google.com → projet → « Books API » → Activer → « Identifiants » → « Clé API », restreinte à Books API et à l’adresse de l’app (https://ton-site/*). Colle-la dans CONFIG.GBOOKS_KEY. Le quota (1 000 requêtes par jour) est partagé entre tous les amis.
  2. TMDB : themoviedb.org → Paramètres → API → « Clé d’API » (v3) → CONFIG.TMDB_KEY.
Admin · Mode administrateur

Touche cinq fois le titre « Réglages » pour afficher ou masquer les options administrateur (source, clé, clés API). Tes amis ne voient que le lien du Sheet.
